# eCommerce Website

Welcome to the eCommerce website project! This is a fully functional online shopping platform built using React.js, JavaScript, CSS, HTML, and Firebase. The project focuses on providing a smooth user experience with dynamic and responsive features.

## Features

### 1. User Authentication
- Secure sign-up and login functionality powered by Firebase Authentication.
- Real-time user session management.

### 2. Shopping Cart
- Add to Cart and Remove from Cart functionality.
- Items persist in the cart until removed by the user.

### 3. Checkout Section
- Dynamic Subtotal calculation for items in the cart.
- Easy-to-understand breakdown of selected items.

### 4. Responsive Design
- Fully responsive design for optimal viewing on mobile, tablet, and desktop devices.
- Modern and clean UI for seamless navigation.

## Technologies Used

### Frontend:
- **React.js**: Component-based architecture for building the user interface.
- **JavaScript**: Logic implementation and interactivity.
- **HTML5**: Markup structure of the application.
- **CSS3**: Styling and layout design.

### Backend:
- **Firebase**: 
  - Authentication: Secure user sign-up and login.
  - Realtime Database: Store and manage data efficiently.

## Installation

Follow the steps below to get a local copy of the project up and running:

### Prerequisites:
- **Node.js**: Ensure you have Node.js installed on your system.
- **npm**: Node Package Manager for installing dependencies.

### Steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/eshop.git
   ```

2. Navigate to the project directory:
   ```bash
   cd ecommerce-website
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Set up Firebase:
   - Create a Firebase project in the [Firebase Console](https://console.firebase.google.com/).
   - Configure the Firebase credentials in a `.env` file:
     ```env
     REACT_APP_FIREBASE_API_KEY=your-api-key
     REACT_APP_FIREBASE_AUTH_DOMAIN=your-auth-domain
     REACT_APP_FIREBASE_PROJECT_ID=your-project-id
     REACT_APP_FIREBASE_STORAGE_BUCKET=your-storage-bucket
     REACT_APP_FIREBASE_MESSAGING_SENDER_ID=your-messaging-sender-id
     REACT_APP_FIREBASE_APP_ID=your-app-id
     ```

5. Start the development server:
   ```bash
   npm start
   ```

6. Open the project in your browser:
   ```
   http://localhost:3000
   ```

## Usage
- Sign up or log in to access the platform.
- Browse through the product catalog.
- Add desired products to your cart and proceed to checkout.
- Enjoy a seamless shopping experience!
